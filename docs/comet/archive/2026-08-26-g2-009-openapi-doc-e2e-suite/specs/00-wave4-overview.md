# Spec — Wave 4 overview

Change `g2-009-openapi-doc-e2e-suite` ships a runtime OpenAPI document endpoint for the v1 (`@teable/openapi`) registry and a HTTP-level E2E smoke suite for the controller layer. Both deliverables are small, additive, and scoped strictly to the new `openapi-doc` feature folder + the new test file.

Two specs cover the change:

1. `specs/01-runtime-openapi-doc.md` — runtime endpoints
2. `specs/02-e2e-suite.md` — E2E test suite

Acceptance IDs are referenced from the brief verbatim.
